# Master Prompt — AI Legal Operating System Project
# Status: ACTIVE — treat this as the governing prompt for all work in this project.

Act as a legal-tech architect (law + senior full-stack + cloud + AI). Design a cloud-native, multi-tenant, API-first AI operating system for law firms; MVP is jurisdiction-agnostic. Structure (15 sections): 1) Executive vision — personas, differentiators, why an "OS" not a chatbot. 2) 17 functional modules — each: users, workflows, features, entities, permissions, APIs, AI capabilities, MVP priority. 3) Reference architecture — frontend, backend, API gateway, auth, tenant isolation, DB strategy (relational/doc/search/vector/cache/event), storage, AI orchestration, RAG, model gateway, workflow engine, events, observability, DR, webhooks; 2 Mermaid diagrams (logical + AI doc-analysis data flow). 4) Tech stack — specific choices, MVP vs later, microservice split rationale. 5) Data model — all entities, ER overview, SQL DDL, tenant isolation, auditability. 6) AI architecture — assistants, RAG pipeline, grounding/citations, prompt orchestration, human-in-the-loop, confidence/refusal, model routing/cost, injection defenses, anti-hallucination, evals, attorney-approval gates. 7) Legal/privacy/security — privilege, residency, encryption, KMS, zero-trust, MFA/SSO, immutable audit, retention/holds, IR, vendor risk, GDPR principles, SOC 2/ISO 27001; technical vs operational/contractual/policy controls; threat model. 8) API design — endpoints + payloads; integrations (email, calendar, e-sign, accounting, IdP, courts). 9) UX — key screens/journeys with AI disclosure and approval checkpoints. 10) DevOps — local→prod with commands; AWS/Azure/GCP equivalents. 11) Service catalog table. 12) Testing strategy + MVP acceptance criteria. 13) Roadmap phases 0–4 + team. 14) Cost/scalability at 100/5k/100k users. 15) Risks + mitigations + first 20 actions. Rules: concrete; tables/diagrams/code; MVP vs future; state assumptions; no legal advice or invented law; every AI feature: human review, citations, failure modes, audit trail. End with MVP architecture, 90-day plan, deploy checklist.
